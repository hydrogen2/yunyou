### Engine note — how a local file gets into the cut

`studio/schema/scene.schema.json` gained `media[].kind: "footage"` (ref = a path relative to the chapter dir) plus
`media[].use` (`player` | `linear` | `both`), `media[].audio` (`mute` | `keep` | `duck`) and `media[].sa` (boolean).
`studio/tools/render/render_linear.mjs` gained `segFootage()` and a `{kind: "footage", media: "M-xx", in_s, dur}`
visual in the cut sidecar; if the file is missing it degrades to the existing pending-asset card, so a clean checkout
still renders. Documented in `studio/templates/scene-spec.md`.
